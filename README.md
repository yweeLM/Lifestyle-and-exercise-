# Know Your Parenting Type

A one-page site for parents of children aged 5–18 that explains why knowing
your parenting type matters, based on *Digital Savvy Parenting* by Yetty
Williams. The main button sends parents to the quiz on Formly.

Built with Vite, React, TypeScript, Tailwind CSS, shadcn-style components,
Motion and lucide-react, styled after the Claude look
(github.com/rubenhassid1/grenade, web version).

```bash
npm install
npm run dev      # local preview
npm run build    # static site in dist/
```

Edit the copy in `src/App.tsx` (the `reasons`, `worlds` and `moments` lists
and `QUIZ_URL`).

Deploy on Vercel: import the repo, pick this branch, framework preset **Vite**.
